# Contributing to QuietFeed

Thank you for helping improve QuietFeed.

1. Open an issue before making a large behavioral or API change.
2. Keep the service single-user and compatible with Reeder Classic unless a change has been discussed.
3. Add tests for bug fixes and new behavior.
4. Run `gofmt -w *.go`, `go test ./...`, and `go vet ./...` before submitting a pull request.
5. Do not commit databases, feed exports, passwords, tokens, or production configuration.
